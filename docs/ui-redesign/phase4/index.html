推荐 原型已实现

  • 阅读效率：最高。860px 单列，视线不横移。
  • 长文本：最好。整列宽度都归题目与反馈。
  • 反馈可读性：好。分数、维度、正文按顺序纵向排列。

  • 成本：最低。主要是分组与进度提示的调整。

推荐：方案 A · 单题专注式

练习页的核心任务是「读题 → 作答 → 读懂反馈」。三者在时间上串行，在空间上应当同处一列。 A 让整页宽度服务于这一件事，B 用任务带换走了阅读高度，C 用侧区换走了阅读宽度—— 两者都在为一个练习页并不紧迫的需求（全局定位、常驻提示）牺牲主线。

更关键的是兼容性：现有 mla-practice 已经是单列 860px 结构，A 是对既有实现的 整理而非推翻；B 需要练习页新增任务上下文读取，C 需要新建侧区组件与移动端 Sheet， 两者都会扩大改动面，而收益在原型中无法证明。

A 的三个具体改进：① 出题表单默认折叠成一行「开始一道新题」； ② 提交 / 评分 / 记录三步做成可见的进度条； ③ 反馈拆成「结果 → 维度 → 正文」三层，不再挤在一个灰块里。
