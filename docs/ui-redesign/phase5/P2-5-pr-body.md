### 关键设计

- **容器查询而非 viewport**：同一列表会出现在桌面宽面板与手机窄卡片里，只有列表自身宽度该决定排列。
  `.mla-knowledge-list { container-type: inline-size }`。
- **断点 560px 由实测确定**：该处单行布局的进度条仍有约 180px；切换后 320px 视口进度条仍有 187px。
- **桌面端保持原样**：单行、原顺序（名称 → 进度条 → 百分比 → 徽章 → 日期 → 展开），名称仍为省略号截断。
- **手机端纵向堆叠**：名称占首行剩余宽度并可换行，徽章固定首行右侧，掌握度与复习日期各占一整行。
- **不隐藏任何元素**：徽章、百分比、展开图标在全部七档视口都可见。
- **无日期不渲染占位**：不再输出 `-`（`-` 会被读成"无需复习"，而那是服务端的复习资格判断）。
