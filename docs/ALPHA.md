# v0.1.0-alpha

源码开发预览。单一学习产品，仅提供 learning 运行入口。

## 已具备

- **五页面学习前端**：今日学习、AI 学习、练习与反馈、我的学习档案、系统设置。
- **响应式布局**：桌面固定侧栏，≤900px 折叠为底部导航；已验证 320×640、360×800、390×844、768×1024、1024×768、1440×900、1920×1080 七个视口，无横向溢出、无内容被裁切、无底部导航遮挡。
- **学习会话与历史**：会话创建、切换、历史恢复；`?page=` 与 `?session=` 为 URL 单一真相，直接访问、刷新、后退、前进都能回到同一段会话。
- **学习检查点**：按会话读取公开状态、显式初始化、暂停与继续，带修订号冲突检测。权威记录保存在本机，元数据中的投影可从权威记录重建。
- **学习档案与模型设置**：复用已有的学习档案面板与通用/模型/关于设置；未恢复已裁剪的 MCP、终端、Office 等能力。

## 尚未实现

- 正式 AI 出题。
- 用户的练习提交与可靠评分。
- 自动学习证据生成。
- 完整的掌握状态评估闭环。
- 智能复习业务闭环。

练习页只提供结构与明确的空状态，不提供无法真正完成的「提交并评分」动作。检查点的**存储与恢复**已打通，但学习闭环本身尚未完成——两者不可混为一谈。

## 本轮验证记录（真实执行）

```powershell
npm run build        # 通过
npx vitest run       # 101 文件 / 824 通过 / 3 跳过 / 0 失败
```

浏览器验收使用 Chrome（CDP 设备模拟）对 7 个视口 × 5 个页面逐页测量：

- 所有页面在滚动到底后无正文或可交互控件留在视口之外；
- 所有页面 `scrollWidth == innerWidth`；
- 移动端「本次学习」「学习会话」卡片位于聊天区下方且可达；
- 390×420（模拟软键盘压缩视口）下输入框与发送按钮仍可操作；
- 深链接、刷新、后退、前进均恢复到同一会话与同一修订号；
- 快速切换会话不会显示另一会话的检查点。

验收截图归档在 `docs/ui/acceptance-*`；S2-2.5 基线截图保留在 `docs/ui/` 下未改名文件。

## 已知限制

- Electron 安装包与 Docker 镜像未在本轮验证范围。
- 公开学习状态只包含检查点摘要与题目正文；评分规则、参考答案与内部评估不对外暴露，因此练习页暂无真实作答数据可展示。
- 聊天功能验证使用本地合成模型服务，不代表真实模型的教学效果。
