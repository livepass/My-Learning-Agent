# E4.8b — AI 学习首页改为对话式欢迎页

目标：把 AI 学习页从「业务后台三栏布局」改成「对话式欢迎页」——先选课程，再开始本次 AI 学习；只有真正进入某个对话后才切换为课程会话布局。E4.8 / E4.8a 的课程绑定规则（会话必须属于课程、首条消息才创建会话、未归类历史只读）全部保持不变。

## 1. 两种页面状态

| 状态 | 判定 | 布局 |
| --- | --- | --- |
| 欢迎态 | `sessionsStore.currentSessionId === null` | 单列：中央欢迎语 + 课程卡片（或快捷操作）+ 底部输入框 |
| 会话态 | 有打开的会话 | 左侧课程对话列表 + 中间聊天 + 右侧可收起「本次学习」 |

欢迎态不渲染课程侧栏，也不渲染右侧学习状态面板，因此中央欢迎区不会被压缩。手机端沿用原抽屉/下方状态面板规则。

## 2. 欢迎态内容

未选择课程：

- 标题「你想学习什么？」，副标题「先选择一门课程，再开始本次 AI 学习。」
- 课程卡片：课程名、状态（进行中/已暂停/已完成）、对话数量、最近学习时间；`archived` 课程不出现，只在页脚「归档课程 N 门」入口可达。
- 卡片之后是「+ 创建课程」卡片。
- 输入框保留但禁用，placeholder「请先选择一门课程，再开始本次 AI 学习」，发送按钮禁用；禁用态连 `onChange` 都不写入草稿。

已选择课程：

- 标题改为「你想在「{课程名}」中学习什么？」。
- 快捷操作卡片：讲解知识点 / 制定学习计划 / 开始练习 / 根据资料提问 / 复习薄弱点。点击只把建议语填入输入框，不自动发送、不创建会话。
- 输入框激活，placeholder「在「{课程名}」中输入你的问题」。
- 该课程已有对话时提供「继续之前的对话 · N」折叠列表；选择课程本身不会打开任何会话。

## 3. 课程状态

沿用 E4.8 规则，只是入口从侧栏换成卡片：

- `in_progress`：可选中并开始对话；
- `paused`：卡片可见，选中后输入区替换为「课程已暂停」+「继续课程」；
- `completed`：只读，输入区替换为「课程已完成」；
- `archived`：不出现在欢迎页卡片中，仅通过归档入口访问。

## 4. 会话态

进入会话后才出现三栏：左侧是当前课程下的对话（含「新建对话」与「返回课程选择」），中间聊天，右侧可收起的学习检查点面板。未归类历史仍然只在会话态侧栏的「未归类历史」分组出现，且不会被改绑到当前课程。
