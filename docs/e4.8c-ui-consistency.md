# E4.8c — My Learning Agent 全站 UI 一致性修订

基准：E4.8b `923446b`。本轮只改视觉与布局，未触碰课程绑定、聊天运行时、学习证据、学习计划与归档规则。

## 1. P0：布局 CSS 覆盖

### 1.1 桌面全局导航宽度

**原因**：E4.8 只在 AI 学习页加了 `.mla-body--compact { grid-template-columns: 64px … }`，
但同特异度的 `.mla-body { grid-template-columns: 184px … }` 写在文件后面，按源码顺序后者生效。
所以 64px 紧凑规则实际从未生效，所有页面都是 184px 侧栏；`.mla-sidebar--compact`
的 `align-items / padding / gap` 同样被后面的 `.mla-sidebar` 覆盖。

**修复**：删掉 `--compact` 分支，把 64px 图标栏做成 `.mla-body` / `.mla-sidebar` 的
唯一基础规则，`AppShell` 不再按页面拼类名。图标按钮居中、隐藏可见文字，
中文名称保留在 `aria-label`，并由共享 `Tooltip` 在 hover / 键盘聚焦时给出页面名与描述。
侧栏原来的两段说明文案迁到「系统设置 → 关于」，64px 栏不再承载文字。

### 1.2 手机端 flush 内边距

**原因**：`.mla-main--flush { padding: 0 }` 在前，`@media (max-width: 900px) .mla-main
{ padding: 20px 16px }` 在后且同特异度，手机端 AI 学习 / 学习档案被重新加上内边距，
在已有内边距的聊天卡外面又叠一层。

**修复**：手机断点内补 `.mla-main--flush { padding: 0 }`，并在 `shell.css.test.ts`
中断言「每个重新设置 `.mla-main` 内边距的 900px 块都必须同时重置 `--flush`」。

两处都用浏览器实测计算样式确认（见第 5 节），不只检查 CSS 文本。

## 2. P1：AI 学习欢迎态 / 会话态

- 欢迎态改为**开放画布**：`.mla-learn--welcome` 去掉 980px 容器与内边距，铺满内容区并使用
  `--inno-chat-bg`；`.mla-chat-card--welcome` 去掉边框、圆角与面板底色。页面上只剩
  欢迎语、课程卡片与底部输入框，不再有一圈后台面板外框。
- 欢迎语列仍是 720px，输入框列与桌面 980px 对齐，进入会话后列宽不变，只有外框出现。
- 输入框仍是同一个 `LearningWorkspace` composer：欢迎态只换 placeholder 并禁用，
  会话态只换位置，不重做样式。
- 会话态三栏、课程列表、学习状态面板与全部发送 / 归属 / 切换逻辑不变。

## 3. P1：全局导航与内容容器

- `AppShell`：导航、顶栏、`main` 全站统一；`main` 只保留两种形态。
- 普通内容页（今日学习、练习、设置、课程详情）由新增 `.mla-page` 统一
  1288px 居中列，页面边距仍是 `.mla-main` 的 24px（手机 20/16px），
  不再每页自己发明最大宽度。
- 沉浸式页面（AI 学习、学习档案）继续 `mla-main--flush`，自己拥有内边距与滚动。
- 顶栏高度、背景与右侧「设置」位置未变，只随导航收窄而获得更多横向空间。

## 4. P2：课程卡片族与通用控件

- 新增共享基类 `.mla-course-card, .mla-course-pick, .mla-quick-card`：同一表面
  (`--inno-surface`)、1px `--inno-border`、10px 圆角、16px 内边距、15px 标题。
- 变体只表达行为：`.mla-course-card` 是带操作行的信息卡；`.mla-course-pick` 是整卡按钮
  （`--create` 用虚线）；`.mla-quick-card` 是单行图标入口。hover / focus-visible / disabled
  由基类统一，不再各写一份。
- `.mla-card` 圆角从 8px 收敛到 10px，与课程卡、输入表面一致。
- 新增 `docs/ui-guidelines.md`：导航与顶栏、两类页面、卡片/按钮/输入框/标签、
  排版与主题、手机端策略。

- 未跑全量 `npx vitest run`（按本轮定向要求），未重跑 E4.7 / E4.8 业务验收。
