# My Learning Agent — UI 规范（E4.8c）

本文件是 `design.md` 的学习产品补充，只覆盖 My Learning Agent 学习壳层
（`web/src/react/shell/`、`web/src/react/pages/`）的规则。通用颜色、字体、
动效与共享控件仍以 `design.md`、`app.css`、`themes.css`、`react/ui/` 为准。

## 1. 全局导航与顶栏

- 桌面端只有一种导航：64px 图标栏（`.mla-sidebar` / `.mla-body`）。不按页面
  切换宽度，也不保留「学习页窄、其他页宽」的分支。
- 图标栏按钮为 44px 高的方形图标按钮，选中态使用 `--inno-accent-soft`
  背景 + `--inno-accent` 图标色；中文名称通过 `aria-label` 与共享
  `Tooltip`（右侧弹出，含页面描述）提供，视觉上不显示文字。
- 侧栏不承载说明文案；说明类内容放到「系统设置 → 关于」。
- 顶栏在所有页面一致：左品牌 + 当前页名称，右侧「设置」入口。高度、内边距、
  边框与背景由 `.mla-topbar` 单点定义。
- ≤900px 时侧栏收起为底部导航，使用短标签（今日/学习/练习/档案），
  其余规则不变。

## 2. 两类页面：普通内容页与沉浸式页面

| 类型 | 页面 | `.mla-main` | 内边距与宽度 |
| --- | --- | --- | --- |
| 普通内容页 | 今日学习、练习与反馈、系统设置、课程详情 | 无 `--flush` | 页面 24px 内边距（手机 20/16px），内容列由 `.mla-page` 限制 1288px 并居中 |
| 沉浸式页面 | AI 学习、我的学习档案 | `mla-main--flush` | 内边距 0，页面自己拥有内边距与滚动 |

- 新增页面时先选择类型，不要自造第三种宽度；页面内部的列宽（如聊天 1100px、
  欢迎语 720px）属于该页内容，不算页面边距。
- 手机端 `--flush` 必须保持 `padding: 0`：卡片本身已有内边距，再加一层会出现
  双层留白。

## 3. 卡片、按钮、输入框、状态标签

### 卡片

- 基础卡片 `.mla-card`：`--inno-surface` + 1px `--inno-border` + 10px 圆角 +
  20px 内边距，网格间距 16px。
- 课程卡片是一个族，共用 `.mla-course-card / .mla-course-pick / .mla-quick-card`
  基类（同一表面、边框、10px 圆角、16px 内边距、15px 标题），只用行为区分：
  - `.mla-course-card`：课程信息卡（今日学习），含任务、进度与操作行；
  - `.mla-course-pick`：可选择的课程卡（AI 欢迎页），整卡是一个按钮；
    `--create` 变体用虚线边框表达「新建」；
  - `.mla-quick-card`：单行快捷入口（图标 + 文字），与选择卡共享 hover /
    focus / disabled。
- 不允许为某个页面复制一份卡片样式；新增变体只能加行为（hover、布局），
  不改表面、圆角与标题字号。

### 按钮

- 一律使用 `react/ui/` 的 `Button` / `IconButton`；页面不手写按钮底色。
- 每个区域只有一个主要动作（`primary`），其余用 `secondary` / `ghost`；
  危险动作用 `danger` 并单独确认。
- 卡片内的次要入口（如「查看课程」「切换课程」）使用 `ghost` + `xs`。

### 输入框

- 聊天输入区是一个组件：欢迎态与会话态共用同一个 composer，只改变位置与
  placeholder，不重新实现一套输入样式。
- 欢迎态未选择课程时 composer 保留可见但禁用（`disabled`），placeholder
  说明原因；禁用态不写入草稿。
- 聚焦只加深外层边框，不加发光；手机端输入字号 16px 以避免 iOS 缩放。

### 状态标签

- `.mla-badge` 为默认标签；进行中/强调用 `--accent`，成功/警告/危险只在
  真实状态时使用对应 token。
- 状态必须同时有文字，不只靠颜色。

## 4. 排版、间距、圆角与主题

- 字号：页面标题 24px（手机 20px），区块标题 16px，卡片标题 15px，正文 14px，
  辅助信息 12px。新增界面不再引入一次性字号。
- 间距：4px 基准，常用 8 / 12 / 16 / 20 / 24。页面标题与内容间距 24px，
  卡片内元素 10–16px。
- 圆角：小控件 8px，卡片与输入表面 10px，弹层沿用 `react/ui/` 的既有值。
  嵌套层不因层级自动变大。
- 颜色只使用 `--inno-*` 语义 token；light / dark 两套主题都要检查。新增颜色
  先加 token，不在组件里写裸色值。

## 5. 手机端响应式策略

- 断点：≤900px 收起侧栏、启用底部导航；≤1100px 收窄学习页三栏；
  容器查询 430px / 640px 处理窄列与宽表格。
- 布局顺序不改变语义：AI 学习手机端聊天卡占满可用高度，学习状态位于其下方，
  页面整体滚动；课程列表为抽屉。
- 不允许横向溢出：长标题换行、宽表格在自身容器内横向滚动、模型名省略。
- 触控区域 ≥44px；消息操作在触屏上常显（`@media (hover: none)`）。
