## 3. 翻译资源校验

新增 `web/src/i18n/locales.test.ts`，覆盖：

1. 学习键在两份资源中同时存在；
2. 动态枚举键（`course.status.*`、`practice.result.*`）逐个校验；
3. 同一键的 `{{变量}}` 集合一致；
4. 复数键按语言规则处理（英文 `_one`/`_other`，中文单数形式），不要求两份 JSON 键完全相同；
5. 学习页面中的固定中文必须已迁移或登记在 `PENDING`（燃尽清单，只减不增）；
6. 任一缺失即测试失败，不依赖运行时中文 fallback。

## 4. 错误信息

错误码（`course_paused`、`course_archived`、`course_required`、`learning_state_invalid` 等）继续按原值传递；显示层映射为本地化文案，未识别的错误显示本地化通用提示并保留服务端诊断信息。
